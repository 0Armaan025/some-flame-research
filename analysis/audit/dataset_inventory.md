Scope: read-only audit of `data/raw/flex/`. Nothing under `data/raw/` was
modified; all values below are transcribed as reported, with no unit
conversion. Generated by `analysis/audit/audit_flex_psi69.py`.

## 1. Source files

## 2. What the experimental table contains per record

| Field group | Variables | Notes |
|---|---|---|
| Identity | Test #, FLEX Identifier, Date, GMT | The only join key to per-run telemetry |
| Nominal environment | Pressure (mmHg), O2/N2/CO2/He mole fractions | Initial ambient composition only |
| Droplet | Initial diameter (mm), visible flame extinction diameter (mm) | Extinction diameter is the *visible flame* diameter, not a measured chemical extinction |
| Burn behaviour | Burning rate (mm, unit ambiguous, see DQ-3), burn time (s) | No instantaneous d²-law trajectory |
| Outcome | Test end: Extinction / Disruption / Completion | Outcome categories, see §3 |

## 5. Linkage to individual FLEX runs

- The `FLEX Identifier` column is a **file-level join key**: 8 identifiers
  (`20CAL08, 20CAL10, 20CAL12, 20CAL13, 30CAL02, 30CAL03, 30CAL06, 40CAL01`)
  have per-run telemetry in `part-01/`; **265 of 274 records have no per-run
  telemetry**.
- All 8 linked runs are 2009 ambient-air (O2/N2 = 0.21/0.79), 757–764 mmHg,
  3 methanol / 5 heptane. Telemetry coverage is therefore **not representative**
  of the broader condition matrix (no He/CO2-diluted or high-pressure run has
  telemetry).
- Within `part-01/`, files for one test share a name prefix but **three
  distinct clock domains** are present (AS/PIP event clock in the main test
  file, FCU clock in chamber readings, PIP clock in radiometer readings), and
  the notebooks `notebooks/audit_flex_clocks.py`,
  `audit_flex_frame_timing.py`, `audit_flex_timeline.py` indicate the offsets
  between them are non-trivial. Any time-linking of telemetry to the
  experimental table requires the clock-sync work those notebooks started.

## 6. Files needed for deeper analysis (not yet integrated)

- `part-01/` `*_Chamber_Readings.txt`, `*_Radiometer_Readings.txt` and main
  test files (8 runs each) — needed for time-resolved chamber environment and
  any flame-signal trace; only after clock-domain reconciliation.
- The A/B/D zip archives (~5.4 GB) — image/FCI data required for any
  geometry-time-series or flame-imaging analysis; not extracted/inventoried
  beyond file names in this phase.
- `docs/flex/FLEX_Test_Plan.pdf`, `FLEX_EIRD_v4.pdf`, `FLEX DoD.docx`,
  `FLEX Overall Ext File-2.pdf`, `i_Investigation.txt` — required to resolve
  the burning-rate unit (DQ-3), confirm the gravity regime per run, and obtain
  ignition/deployment method definitions.
- Per-run temperature and fuel-purity information — **absent from every
  available source file** surveyed here.
